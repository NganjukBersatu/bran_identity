# Web (Frontend)

Landing page software house, dibangun dengan Vue 3 + Vite.

## Menjalankan project

npm install
npm run dev

## Struktur komponen

src/components/ berisi 1 file per section, urutannya sudah diatur di App.vue:
Header -> Hero -> ClientLogos -> Services -> WhyUs -> Process -> Portfolio -> Testimonials -> CTA -> Blog -> Footer

## Aset yang perlu ditambahkan (di folder public/)
- logo.svg (logo perusahaan, versi warna, untuk header)
- logo-white.svg (logo perusahaan, versi putih, untuk footer)
- hero-illustration-developer.svg (sudah dibuat, tinggal ditaruh di public/)
- team-photo.jpg (foto tim/kantor untuk section WhyUs)
- logos/klien-1.png dst (logo klien, untuk ClientLogos)
- portfolio/project-1.jpg dst (screenshot project)
